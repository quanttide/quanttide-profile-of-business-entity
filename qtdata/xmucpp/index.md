# 电商价格数据库

## 需求

两个电商平台，每天采集一次，采集365天。

根据固定关键词列表进入搜索页获取商品列表及价格和销量，并进入商品详情页获取商品规格。

## 规格

### 契约

缺失值不能高于30%

### 蓝图

可能由于采集器故障导致价格数据缺失。

当单天数据缺失时，如果前后两天数据没变，在非促销活动日假设它也没变，是一个可以接受的缺失。

因为根据观察，电商价格变化在非促销日一般不会突然变化又回撤。

如果促销日缺失，则视为违背数据契约。

## 实现

### 目录

每天每关键词存一个CSV。

### 流水线

三个步骤：
1. 商品类别分配器
2. 商品列表采集器
3. 商品详情采集器
