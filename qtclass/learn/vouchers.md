# 代金券（Vouchers）

实训基地的内部激励货币：参与真实劳动获得，可用于购买专家时间与考核额度。

## 怎么挣

| 方式 | 报酬 |
|---|---|
| 完成课堂实训任务 | 100 券/个 |
| 完成众包任务 | 基准 1000 元/任务 |
| 课题通过初审 | 奖励 500 券 |
| 担任代表参与课题评审 | 100 券/次 |

渠道持续扩展中——参与课堂教学活动、支持活动等均在计划内。

## 怎么花

| 用途 | 价格 |
|---|---|
| 一对一咨询（按专家职级） | 首席 500 / 资深 400 / 高级 300 / 中级 200 / 初级 100 元每小时 |
| 购买超额申请额度 | 立项超 1 次 / 交付超 3 次后，100 券/次 |

## 规则要点

- **群内沟通免费**——日常提问不消耗代金券；群是训练的一部分（"不提问、不沟通就过不了"）
- 代金券用于一对一深度交流与考核额度——本质是为**稀缺的专家时间**与**评审资源**定价
- 制度逻辑："这套考核体系同时也就是教育体系，所以会为它进行必要的定价"——用货币感知资源的真实成本，本身就是学习的一部分
