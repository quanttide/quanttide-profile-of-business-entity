# 价格（Prices）

实训学习的价格体系：参与免费，一对一咨询按专家职级定价。

## 任务参与免费

| 方式 | 费用 |
|---|---|
| 课堂实训任务 | 免费 |
| 训练营 | 免费 |
| 众包任务 | 免费 |
| 群内提问与日常沟通 | 免费 |

完成课堂实训任务、众包任务等可获得**代金券奖励**（如课堂实训任务 100 券/个、众包任务基准 1000 元/任务），代金券可用于预约一对一咨询。

## 一对一咨询定价

一对一咨询**按小时计价，价格与专家职级档位对应**：

| 职级 | 价格 |
|---|---|
| 首席 | 500 元/小时 |
| 资深 | 400 元/小时 |
| 高级 | 300 元/小时 |
| 中级 | 200 元/小时 |
| 初级 | 100 元/小时 |

- 预约方式：群内联系对应支持者，或通过支持人员转介。
- **群内提问免费**——日常沟通不消耗任何费用，能公开解决的问题不建议约一对一。
