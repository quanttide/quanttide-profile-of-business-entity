# 实训学习（Learn）

从学习到入职的成长通道：以真实工作为课堂，在参与公司真实业务中完成学习、产出与筛选。

## 业务定位

实训学习的课堂不是教学场景，而是**公司真实业务本身**：

- 课题来自公司真实挑战——学员面对的不是练习题，而是待交付的真实工作（客户支持、产品、数据工程、商务）
- 交付标准与公司一致：成果必须能被没有经验的新人在系统支持下独立复现
- 学习、产出、筛选三合一：参与即学习，产出即工作成果，表现即考核依据

## 学习方式

| 方式 | 说明 |
|---|---|
| 课堂任务 | 完成教学任务（如开源协作入门），获得代金券 |
| 课题实践 | 申请立项、独立交付一个真实方向的小课题 |
| 众包任务 | 承接公司发布的真实商业任务 |
| 一对一咨询 | 与不同职级的专家预约深度交流 |
| 代表履职 | 表现优秀者参与课题评审等基地治理，有报酬 |

## 成长进度条

以负数职级标示相对公司招聘标准的位置：-3（纯学员）→ -2（可参与小贡献）→ -1（可较独立贡献）→ **0（可入职）**。负数是"商场地下楼层"，不代表能力是负的——它是每个人从首次参与到获得公司身份的可见路径。

## 代金券制度

参与以上活动获得代金券；代金券用于预约一对一咨询（按专家职级定价）与购买额外的课题申请额度。详见各参与方式说明。
