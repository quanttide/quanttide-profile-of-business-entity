# 基地治理（Governance）

实训基地有自己的治理结构——代表大会是最高决策机构。参与治理不是模拟，你在其中拥有真实的提案权、投票权与报酬。

## 治理结构

```
实训基地代表大会（最高决策机构）
  ├─ 代表：提案权 + 投票权
  ├─ 秘书长 / 主席：主持日常，代表公司行使一票否决（很少使用）
  └─ 上议院：公司代表大会兼任，审议基地决策
创始人：不直接参与日常，通过股东代表大会行使一票否决（很少使用）
```

## 代表的权力与报酬

- **提案权与投票权**：参与制定实训基地管理规则，按议题参与情况获得激励
- **课题初审**：参与课题立项与结项的初审，每次 100 代金券。初审环节已实际下放给代表（邮件交接），公司对结果负责以保证公平与专业
- **让渡范围**：课题初审、基地运营、人员选拔、代表资格选拔逐步交由代表大会——公司保留的只有一票否决

## 怎么成为代表

- **冷启动**：由公司任命初始代表（第一批为一位学员与三位招聘候选人）
- **常态化**：后续的提案与提名由代表们自行制定与选拔——持续活跃、课题通过初审者有机会进入视野
- **运营权**：基地运营（包括群本身的运营）可开放为课题申请，决策权让渡给代表大会

## 法治与民主

- **法治**：能成文的全部成文，不能成文的遵循惯例——章程公开可查
- **民主**：参考人大命名方式与英美议会组织习惯，代表按议题参与情况履职

## 为什么设置代表制度

- **代表资格 = 核心成员的后备役**：代表是培养和选拔中非常关键的一个节点——通过代表大会，把实训基地能承担的权利（初审权、制度建设权）逐渐转移过来
- **评审是 AI 原生组织的基本能力**：大家产生交付的速度太快，必须验收——公司至少 40% 以上的工作在评审。评审能力在这里不是选修课，而是基本工作能力
- **标准不是公司强加的**：每个员工自然而然地进入工作流后，会发现很多标准是大家一致共同的东西——比如没有人希望看到一个「水」的、浪费时间的课题申请

## 制度即培养

代表资格的权力有多大，取决于你怎么用。学会使用正式制度协调不同的人达成目的——这本身就是培养与选拔机制的一部分，也是这里希望你带走的能力。
