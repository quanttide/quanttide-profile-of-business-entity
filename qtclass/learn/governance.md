# 基地治理（Governance）

实训基地是独立治理的主体：自己的规则自己立、自己的证明自己发、自己的事务代表大会审。代表大会是最高决策机构——你在其中的提案权、投票权与报酬都是真实的，不是模拟。

## 治理结构

```
实训基地代表大会（最高决策机构）
  ├─ 代表：提案权 + 投票权
  ├─ 秘书长 / 主席：主持日常，代表公司行使一票否决（很少使用）
  └─ 上议院：公司代表大会兼任，审议基地决策
创始人：不直接参与日常，通过股东代表大会行使一票否决（很少使用）
```

## 公司与基地的关系

实训基地与公司是两个主体：

- **审批路径**：课题立项、结项、实训/实习证明——先向代表大会提交，通过后再给公司。代表大会是第一审批主体
- **公司角色**：委托方与兜底方——把事项委托代表大会初审，对结果负责以保证公平与专业；出了问题，公司兜底
- **否决权**：公司保留一票否决但很少使用——存在本身维持秩序

## 代表的权力与报酬

- **提案权与投票权**：参与制定实训基地管理规则，按议题参与情况获得激励
- **初审权**：课题立项与结项的初审，每次 100 代金券。初审已实际下放（邮件交接），代表已能独立给出「退回修改」级别的专业评审意见
- **证明签发**：实训证明、实习证明的规则制定与初审，由代表大会负责
- **规则生成权**：议事方式、提交方式等由代表们自己定——立法权在基地内部生成，不从公司继承
- **让渡范围**：课题初审、结项、证明签发、基地运营、人员选拔逐步交由代表大会；公司保留的只有一票否决

## 怎么成为代表

- **冷启动**：由公司任命初始代表（第一批为一位学员与三位招聘候选人）
- **常态化**：后续的提案与提名由代表们自行制定与选拔——持续活跃、课题通过初审者有机会进入视野
- **运营权**：基地运营（包括群本身的运营）可开放为课题申请，决策权让渡给代表大会

## 法治与民主

- **法治**：能成文的全部成文，不能成文的遵循惯例——章程公开可查（如课题立项评审章程：方向判断与质量控制分离，技术/工具/平台不作为方向依据）
- **民主**：参考人大命名方式与英美议会组织习惯，代表按议题参与情况履职；议事原则是参与审议的范围扩大到最大

## 为什么设置代表制度

- **代表资格 = 核心成员的后备役**：通过代表大会，把实训基地能承担的权利（初审权、制度建设权）逐渐转移过来——锻炼的是治理自己的组织
- **评审是 AI 原生组织的基本能力**：交付的速度太快，必须验收——公司至少 40% 以上的工作在评审
- **标准是客观的**：标准不是公司强加的，也不取决于一两个老板觉得对不对——考核很大程度上取决于市场能不能接受。章程立清楚，代表就能给出明确的标准

## 制度即培养

代表资格的权力有多大，取决于你怎么用。学会使用正式制度协调不同的人达成目的——这本身就是培养与选拔机制的一部分。基地的事务：公司兜底，你们做主。
